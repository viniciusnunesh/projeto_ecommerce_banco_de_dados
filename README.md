# projeto_ecommerce_banco_de_dados
Projeto acadêmico da disciplina de Banco de Dados, desenvolvido no 4º período de Ciência da Computação da Universidade Católica de Pernambuco (UNICAP). Inclui modelagem conceitual e relacional, normalização até 3FN, implementação em MySQL, integridade referencial e consultas SQL em um sistema de e-commerce.
